## Варианты

**A — выбран: локальный refactor существующего TypeScript hook с нормализацией *до* склейки соседних assistant-строк.** Реконструкция модели остаётся в `src/transcript.ts::dedupeReplayedHistory` / `engineMessages`, а код `hooks/fast-jev.ts::register` сохраняет поддерживаемые event hooks, OpenRouter/Jev, `writeCallPages`, привязку tool-use/results и запрет fallback. При каждом replay идентичность повторов — минимум `user turn + assistant segment/tool id`, не глобальная строка. Отдельно защитить assistant text, уже объединённый `engineMessages` через `joinText`: повторную разбивку по `\n\n` без происхождения **не** делать, поскольку это разрушает законные сообщения. Реализация должна сохранять provenance сегментов до объединения или ограничить объединение доказуемо недублирующимися чанками; не удалять введённый владельцем текст и реальные повторы другого turn. В `turn.complete` убрать автоматическое `$.session.compact()` и threshold/retry ветку, **оставив** замер `effectPending` первого model request; ручной `session.compact` и Jev errors→`{skip}` остаются. В отчётах `visibleTokens` — оценка удержанных сообщений, `$.session.usage().context.tokens` — измеренное значение *первого запроса*; встроенная Desktop-строка `saved N` вне control surface hook. **Плюсы:** минимальный diff, существующий API и тесты, нет новой долговременной чувствительной копии истории. **Риски:** engine может уже передать слитую строку без идентичностей; тогда plugin не имеет безопасного критерия для восстановления границ и должен пометить UI-only/engine-only кейс как нерешённый.

**B — отдельный persistent shadow-ledger событий/контента, который обрабатывает replay поверх движка.** Sidecar хранит fingerprints/turn mapping и пытается восстанавливать model context независимо от `session.compact`. **Плюсы:** потенциальная диагностика разных перезагрузок и idempotent dedup. **Минусы:** новый sensitive state, миграции, многозаписность, новая очередь ошибок и рассогласование с append-only журналом движка. Простейший global content SHA вызывает ложные удаления ассистентского текста в *следующем* ходе; безопасный sidecar потребует полноценного per-turn provenance и будет дублировать механизмы A без подтверждённого выигрыша. Sidecar **не** обещает исправить UI, управляемый Claude Desktop.

**C — заменить текущую компактацию встроенным Claude summary либо другим сторонним fork/plugin.** Новая transport/SDK цепочка могла бы проще входить в API движка, но теряется Jev-only manual compact, невосстанавливаемые страницы, контроль user/assistant text и прозрачное error→skip; добавляются миграция и риск расходов подписки. Никакого подтверждённого решения Desktop renderer или строк `saved N` такой swap не даёт. **Отклонить** без нового доказательного основания; аналогичный upstream Issue — источник ограничений, не готовый релиз.
